# An-lisis-financiero-Grupo-Arcor-2024
Hice un análisis básico de los estaods financieros de Arcor usando excel, para realizar el mismo utilicé un extractor de datos para estados financieros usando python. 

Analicé el grupo desde 2023-2024. 
Es fundamental no solo el analisis de los indicadores elegidos en base de los estados, si no en la herramienta de extracción de datos usando python en el que se adapta a la situación de formato del pdf. 

Estructura de análisis:
Balance general, Estado de resultados, Flujo de efectivo, Estructura de deuda, Obligacioens negociables. 

Analicé estos indicadores: 
-Liquidez
-Endeudamiento
-Rentabilidad
-Retorno
